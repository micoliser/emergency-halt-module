# Demo video outline (60–90s) — v1.1

Record on Studionet with the live Demo Vault protocol. Prefer **Path A** if you
only shoot one take (challenge + timeline is the v1.1 differentiator). Path B
is a strong second take or mid-video cut.

## Voiceover pitch (≤20s)

> Anyone can prove an active exploit with a bonded report. GenLayer validators
> fetch the evidence and halt the protocol. Opt-in apps like this vault freeze
> withdrawals. Anyone can challenge a false alarm; named backups can prove a
> fix — same stake size, full incident timeline.

## Shot list — Path A (~70s)

| Time | Shot | On screen |
|---|---|---|
| 0–8s | Home / brand | One-line pitch; Studionet badge |
| 8–18s | Demo Vault | Deposit + withdraw while ACTIVE |
| 18–35s | Report | Paste incident rentry; show risk notice; MetaMask `B` |
| 35–45s | Halted vault | Withdraw blocked; appeal countdown |
| 45–65s | Challenge | Switch to non-authority wallet; overturn rentry; risk notice |
| 65–80s | Timeline close-up | `REPORT` → `CHALLENGE` `[false_alarm]`; dispositions; ACTIVE |
| 80–90s | Vault again | Withdraw succeeds |

## Shot list — Path B (~60s)

| Time | Shot | On screen |
|---|---|---|
| 0–10s | Halt already live | Or quick report |
| 10–25s | Backup wallet | Authority list shows backup |
| 25–45s | Lift halt | Remediation rentry; risk notice (burn on fail) |
| 45–60s | Timeline + vault | `UNHALT_EVALUATED` pays reporter; withdraw works |

## Do not skip

- Exact bond amount in MetaMask
- Timeline with two distinct consensus steps (not one overwritten summary)
- Honest beat: “AI judges page text; bonds are the brake”
